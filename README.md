# ViziTrack (DVMS): Digital Visitor Management System

A secure system that replaces paper visitor logbooks with digital registration, check-in/check-out tracking and access control.

## Status
🚧 In development

- **Working:** The core system is fully functional (staff login, visitor registration, and check-in/check-out tracking). The working code is currently in a private repository; this repository holds the project structure.
- **Planned:** QR visitor passes, role-based access control, automated reporting

## Objectives
- Secure staff authentication
- Digital capture of visitor details
- Check-in and check-out timestamps
- Centralized cloud storage on Supabase

## Tech Stack
Java (Android Studio) · Supabase (database and authentication) · Git/GitHub

## Getting Started
1. Clone the repo: `git clone https://github.com/Linah-debugger/DVMS.git`
2. Open it in Android Studio
3. Create a Supabase project and put your URL and key in a local `local.properties` file (never commit it)
4. Run the app
